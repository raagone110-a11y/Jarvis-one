# JARVIS Accessibility Service Guide

## What is this?

This is an **optional Advanced Mode** feature.

It allows JARVIS to have deeper assistance capabilities (similar to how Voice Access works) when you explicitly turn it on.

## Important Rules

- JARVIS **never** turns this on automatically.
- You must enable it yourself from Android settings.
- You can turn it off anytime.
- Standard Mode (normal permissions) continues to work even if this is off.

## How to Enable

1. Install the latest JARVIS APK
2. Open **Phone Settings**
3. Go to **Accessibility**
4. Find **Downloaded apps** / **Installed services**
5. Tap **JARVIS**
6. Turn the switch **ON**
7. Confirm the system warning

## How to Disable

Same path → turn the switch **OFF**

## Current Status

Foundation is ready. Actual advanced automation logic will be added carefully in future updates while keeping safety rules.
