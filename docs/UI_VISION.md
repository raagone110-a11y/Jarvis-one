# JARVIS UI Vision – Mor Pankh Theme

## Concept
Lord Krishna’s peacock feather (Mor ke pankh) inspired dark theme.

### Color Palette
- Deep night blue / black background (`#0B0F1A` / `#0D1117`)
- Peacock green accents (`#0D7377`, `#14A3A8`)
- Soft gold / cream for highlights (`#D4AF37`, `#E8D5A3`)
- Soft white text (`#E6EDF3`)

### Branding
- App open → elegant logo moment with peacock feather motif + “JARVIS” text
- Status indicators in peacock green / gold
- Buttons and input bar with subtle rounded feather-inspired feel

### Future
- Custom vector peacock feather icon
- Splash screen with fade animation
- Optional animated feather accent
